# AI Disclosure

---

I have been passionately developing scripts and other handy tools for over 10 years. All the code you see here is hand-written by me, unless otherwise specified. LLMs are a good tool for some aspects, but should not be relied upon for actual development. They are not always correct, hallucinate critical errors, and also just generally lower critical thinking skills. Unless otherwise noted in a project directory, all code in this repository is written by a human - me, specifically. That is not to say AI wasn't used, it was - like any tool, it can be helpful when put to the right use. In my case, that would be documentation. I am a wiz at figuring out how to piece a whole bunch of different parts into beautiful, working machinery. However, my documentation has always been lackluster. It exists, but doesn't do a great job.

Having said that, rest assured that *every line* of documentation is reviewed by me, an actual human, and modified/corrected as necessary.
